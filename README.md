# グラフメモ

生成元から矢印で枝を生やしてアイディアを発展させるメモアプリ。

## 仕様
- v1.1: 円の大きさを編集画面のスライダーで変更可能（50%〜250%）
- v1.1: 円ごとに色が少しずつ違う（生成元ごとに色相がずれ、子は親から+18°、結合は2色の中間色）。円は半透明の放射グラデーションで描かれ、重なった部分は色が混ざってグラデーションになる。生成元は太い枠で区別
- ※v1.0の保存データはそのまま引き継がれる（色は自動で割り当て）
- グラフ構造: 1つの丸が複数の丸とつながれる
- 結合: 2つの丸から新しい丸を作り、両方から矢印が入る。本文は2つの本文を連結して初期入力
- 権限ゼロ（通信なし、広告なし、トラッキングなし）/ 約21KB / Android 8.0以上
- データは端末内に自動保存

## 操作
- ＋生成元: 生成元を追加
- ＋子: 選択中の丸から矢印付きの子を追加
- 接続: 選択中の丸を元にして、次にタップした丸へ矢印を引く
- 結合: ボタンを押してから丸を2つタップ
- 削除: 選択中の丸と、それにつながる矢印を削除
- タップ: 選択 / ダブルタップ: タイトル・本文・生成元フラグの編集
- ドラッグ: 丸の移動 / 背景ドラッグ: スクロール / ピンチ: 拡大縮小
